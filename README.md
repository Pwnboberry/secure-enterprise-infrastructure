# Secure Enterprise Infrastructure

Enterprise infrastructure deployment project built in a virtual lab.

![](https://github.com/Pwnboberry/secure-enterprise-infrastructure/blob/main/network-topology.png)
 
## Project Overview

This project demonstrates the deployment and configuration of a small enterprise infrastructure based on Active Directory, Windows Server, Ubuntu Server and Samba.

The project includes:

- Active Directory Domain Services
- Organizational Units and user management
- Windows 10 domain joining
- Ubuntu domain integration
- Samba file server
- Group Policy Objects (GPO)
- Windows auditing
- Backup and recovery
- Automation with PowerShell and Bash
