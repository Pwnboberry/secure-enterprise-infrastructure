# Модуль 3. Ввод клиентской рабочей станции Windows 10 в домен

## Цель модуля

Присоединить клиентскую рабочую станцию **win-pc01** к домену **company.local**, выполнить вход под доменными пользователями и проверить работу централизованной аутентификации и разграничения доступа к сетевым ресурсам.

---

## Выполненные действия

### Проверка сетевых параметров

Перед вводом компьютера в домен была проверена конфигурация сетевого адаптера.

Особое внимание было уделено настройке DNS-сервера, который должен указывать на контроллер домена **WIN-SRV (192.168.10.10)**. Корректная работа DNS является обязательным условием для успешного присоединения рабочей станции к домену Active Directory.

![](https://github.com/Pwnboberry/secure-enterprise-infrastructure/blob/main/screenshots/module_03/dns.png)

---

### Присоединение рабочей станции к домену

На клиентском компьютере **win-pc01** через свойства системы было изменено членство компьютера с рабочей группы на домен.

В качестве имени домена указан:

```text
company.local
```
![](https://github.com/Pwnboberry/secure-enterprise-infrastructure/blob/main/screenshots/module_03/добавление%20пк1%20в%20домен%202.png)

Для выполнения операции использовалась учетная запись администратора домена **COMPANY\Administrator**.

После успешного завершения процедуры компьютер был автоматически добавлен в Active Directory.

---

### Перезагрузка рабочей станции

После изменения членства компьютера была выполнена перезагрузка системы.

После загрузки рабочая станция стала полноценным участником домена **company.local**.

![](https://github.com/Pwnboberry/secure-enterprise-infrastructure/blob/main/screenshots/module_03/вход%20пк1%20в%20домен%20иван.png)

---

### Проверка доменной аутентификации

После присоединения к домену был выполнен вход под доменным пользователем.

Для проверки использовалась учетная запись:

```text
COMPANY\ivan
```

Авторизация прошла успешно.

Корректность входа была дополнительно подтверждена командой:

```cmd
whoami
```
Результат выполнения должен быть таким:

```text
company\ivan
```

Это подтверждает успешную работу механизма доменной аутентификации Active Directory.

---

### Проверка доступа к сетевым ресурсам

После успешного входа была выполнена проверка доступа к общим сетевым папкам сервера.

Использовался сетевой ресурс:

```text
\\WIN-SRV\Shares
```
![](https://github.com/Pwnboberry/secure-enterprise-infrastructure/blob/main/screenshots/module_03/доступ%20к%20папке%20%20с%20ивана.png)

Полученные результаты:

| Каталог | Доступ |
|----------|:------:|
| IT | ✅ |
| HR | ❌ |
| Reports | ❌ |

Пользователь **Ivan** получил доступ только к каталогу своего подразделения, что подтверждает корректную работу настроенных групп безопасности и NTFS-разрешений.

---

## Результат

В результате выполнения модуля клиентская рабочая станция **win-pc01** была успешно присоединена к домену **company.local**.

Подтверждена корректная работа следующих компонентов инфраструктуры:

- доменная аутентификация пользователей;
- централизованный вход в систему;
- разрешение имен через DNS Active Directory;
- применение групп безопасности;
- разграничение доступа к сетевым ресурсам в соответствии с назначенными правами.

Рабочая станция полностью подготовлена для дальнейшего применения групповых политик, настройки аудита безопасности и централизованного управления пользователями домена.
