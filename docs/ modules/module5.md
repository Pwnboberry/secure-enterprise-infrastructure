# Модуль 5. Настройка файлового сервера Samba

## Цель модуля

Развернуть файловый сервер **Samba** на базе **Ubuntu Server**, интегрированный с доменом **company.local**, предоставив доменным пользователям централизованный доступ к общим сетевым ресурсам.

---

## Выполненные действия

### Установка Samba

Для организации файлового сервера были установлены необходимые компоненты:

- Samba;
- SMB Client;
- Winbind.

Установленные службы обеспечивают публикацию общих ресурсов и взаимодействие с инфраструктурой Active Directory.

---

### Создание общей директории

На сервере Ubuntu был создан каталог для размещения общего сетевого ресурса.

Структура каталога:

```text
/srv/samba/share
```
![](https://github.com/Pwnboberry/secure-enterprise-infrastructure/blob/main/screenshots/module_05/папкa%20для%20шары.png)

Данный каталог используется в качестве основной общей папки, доступной пользователям домена.

---

### Настройка прав доступа

Для корректной работы с доменными пользователями были настроены владельцы и права доступа к каталогу.

Владельцем каталога назначена системная группа доменных пользователей, полученная через Winbind.

```bash
sudo chown -R root:20513 /srv/samba/share
```

Права доступа были настроены таким образом, чтобы пользователи домена могли создавать, изменять и удалять файлы внутри общей папки.

```bash
sudo chmod -R 0775 /srv/samba/share
```

Использование групповых разрешений обеспечивает централизованное управление доступом без необходимости создавать локальные учетные записи.

---

### Настройка конфигурации Samba

В конфигурационный файл **/etc/samba/smb.conf** была добавлена секция общего ресурса.

Для опубликованного каталога были настроены следующие параметры:

- публикация ресурса в сети;
- разрешение записи;
- запрет гостевого доступа;
- доступ только для пользователей домена;
- автоматическое назначение группы Domain Users;
- настройка масок создаваемых файлов и каталогов.

После внесения изменений конфигурация была проверена встроенной утилитой **testparm**, подтвердившей отсутствие ошибок.

![](https://github.com/Pwnboberry/secure-enterprise-infrastructure/blob/main/screenshots/module_05/конфиг%20Samba%20etcsambasmb.conf.png)

---

### Добавление пользователей Samba

Для обеспечения доступа через протокол SMB были зарегистрированы доменные пользователи в базе данных Samba.

После регистрации пользователи получили возможность проходить аутентификацию при подключении к файловому серверу.

---

### Перезапуск служб

После завершения настройки были перезапущены службы:

- smbd;
- nmbd;
- winbind.

Перезапуск позволил применить новую конфигурацию без переустановки системы.

---

### Проверка интеграции с Active Directory

Для подтверждения корректной работы Winbind были выполнены проверки получения информации о пользователях домена.

Проверка показала, что сервер успешно получает сведения о пользователях Active Directory и корректно взаимодействует с контроллером домена.

Также была подтверждена корректная регистрация сервера в домене **company.local**.

![](https://github.com/Pwnboberry/secure-enterprise-infrastructure/blob/main/screenshots/module_05/роверка%20интеграции%20с%20Active%20Directory.png)

---

### Проверка сетевого доступа

После завершения настройки была выполнена проверка подключения к опубликованному сетевому ресурсу с рабочей станции **win-pc01**.

Использовался сетевой путь:

```text
\\192.168.10.12\share
```

Проверка была выполнена под всеми доменными пользователями.

![](https://github.com/Pwnboberry/secure-enterprise-infrastructure/blob/main/screenshots/module_05/Проверили%20доступ%20с%20Windows.png)

Все пользователи успешно прошли доменную аутентификацию и получили доступ к общей папке Samba.

---

## Используемые технологии

| Технология | Назначение |
|------------|------------|
| Samba | Файловый сервер SMB/CIFS |
| Winbind | Интеграция Samba с Active Directory |
| Active Directory | Централизованная аутентификация |
| Kerberos | Доменная авторизация |
| SMB/CIFS | Сетевой файловый доступ |

---

## Результат

В результате выполнения модуля на сервере **ubuntu-srv** был успешно развёрнут файловый сервер Samba, интегрированный с инфраструктурой **Active Directory**.

Выполнены следующие задачи:

- установлен файловый сервер Samba;
- создан общий сетевой ресурс;
- настроены права доступа к каталогу;
- опубликована общая папка в сети;
- реализована аутентификация пользователей через Active Directory;
- подтверждено взаимодействие Samba и Winbind;
- проверен доступ пользователей домена к сетевому ресурсу.

Полученная конфигурация обеспечивает централизованное хранение данных и станет основой для последующих модулей, связанных с политиками безопасности, аудитом и резервным копированием.
